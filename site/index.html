Your type hints are the whole spec.

featherweb is an async web framework for Python. Write controllers, annotate the handlers, and it works out the rest: where each argument comes from, what gets a 422, and what the response looks like. It includes its own server and uses nothing outside the standard library.

pip install featherweb

Import cost

Weighed against the others

What import <framework> costs before the first request. You pay it on every process start, including CLI tools, serverless cold starts and each run of the test suite.

    Best of 7 runs of python -X importtime, counting everything the import loads beyond a bare interpreter. CPython 3.12 on one Windows desktop, measured with benchmarks/compare.py. Run it on your own machine before relying on the numbers. Throughput behind the same uvicorn is in the same range as Starlette's.

    Included

    What ships in the box

    Each piece below ships with the framework and is loaded only when something uses it, so an app that never opens a WebSocket never imports the WebSocket code.

    Controllers

    Routes grouped the way you think about them

    A class per resource, one prefix, and guards and error handlers that apply to the whole class. Anything the framework cannot provide is an error at startup, not a 500 in production.

    @Route("/users")
@Authenticated
class UserController:
    @Get("/{user_id:uuid}")
    async def show(self, user_id: UUID) -> PublicUser: ...

    @Delete("/{user_id:uuid}")
    @Roles("admin")
    async def remove(self, user_id: UUID) -> None: ...  # 204
    Server

    Its own HTTP/1.1 and WebSocket server

    Strict limits by default, request-smuggling defences, TLS and multiple workers. It is ASGI underneath, so uvicorn, hypercorn and granian run the same app unchanged.

    featherweb run app:app --port 8000
featherweb run app:app --workers 4
uvicorn app:app            # also fine
    Authentication

    Sessions, JWT and roles

    Signed-cookie sessions or bearer tokens behind one setting. JWT follows RFC 8725: you name the algorithms, and alg: none is always refused.

    auth = JWTAuth(SECRET, algorithms=["HS256"])
app = App(controllers=[UserController], auth=auth)

token = auth.issue("ada", roles=["admin"])
    Real time

    WebSocket in the same controller

    Framing, masking and ping/pong happen below the handler, in whichever server is running.

    @Ws("/echo")
async def echo(self, ws: WebSocket) -> None:
    await ws.accept()
    async for message in ws.iter_text():
        await ws.send_text(f"echo: {message}")
    Files

    Uploads, downloads and streams

    Uploads are parsed as they arrive and spooled to disk past 1 MB. File responses handle ETag, 304 and Range requests without extra code.

    @Post("/upload")
async def upload(self, document: UploadFile) -> dict[str, int]:
    return {"size": document.size}  # spooled, never all in memory
    Testing

    Tests without a socket

    TestClient calls the app directly and runs its startup and shutdown hooks.

    async with TestClient(app) as client:
    response = await client.post("/tasks", json={"id": "x"})
assert response.status == 422
    Comparison

    How it sits among the others

    featherweb takes typed input and output from FastAPI and Litestar, and the small footprint from Starlette and Falcon. It deliberately leaves out dependency injection.

    featherwebFastAPIStarletteLitestarFlaskFalcon

    Pick FastAPI or Litestar if you want generated OpenAPI docs, dependency injection, Pydantic and a large ecosystem.

    Pick featherweb if you want typed controllers, an included server and auth, and no dependency tree to maintain.
